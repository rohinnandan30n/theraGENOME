# Seed Data Generation Guide

## Overview

The `scripts/seed_patients.py` script generates 100 synthetic HIPAA-safe patient records with realistic demographics using the Faker library. This enables local development with representative data without compromising patient privacy.

---

## Quick Start

### Generate 100 Synthetic Patients

```bash
# Activate environment
source venv/bin/activate  # Windows: venv\Scripts\activate

# Generate default 100 patients
python scripts/seed_patients.py
```

### Generate Custom Number of Records

```bash
# Generate 500 patients
python scripts/seed_patients.py 500

# Generate 1000 patients
python scripts/seed_patients.py 1000
```

## What Gets Generated

### Demographic Distribution

Each synthetic patient includes:

| Field | Generated By | Distribution |
|-------|--------------|---------------|
| **patient_id** | UUID v4 | Random, globally unique |
| **first_name** | Faker | Real-sounding first names |
| **last_name** | Faker | Real-sounding surnames |
| **date_of_birth** | Gaussian distribution | Mean age ~50 years (18-95 range) |
| **sex** | Random choice | M (35%), F (35%), Other (15%), Prefer not to say (15%) |
| **ethnicity** | Random choice | 9 options: Caucasian, African American, Hispanic/Latino, Asian, etc. |
| **created_at** | Current timestamp | Now (UTC) |
| **updated_at** | Current timestamp | Now (UTC) |
| **deleted_at** | NULL | All records active (no soft deletes in seed) |

## Data Privacy & HIPAA Compliance

### ✅ Safe for Development

- **All patients are synthetic** - Generated by Faker, not real people
- **No real PII in production** - Patient records are fake names & dates
- **Can be checked into git** - Safe to share among dev team
- **No privacy violations** - HIPAA does not apply to de-identified testing data

### ✅ Privacy Features

- UUID generation prevents ID guessing attacks
- Age distribution realistic (no pattern like sequential DOBs)
- Demographics representative but not traceable to real individuals
- Can be committed to version control safely

### ⚠️ Important Notes

- **Use only for development/testing** - Do not use in production
- **Set expiration dates** - Seed data should be refreshed periodically
- **Clear before production** - Always backup and test before production deployment
- **Access controls** - Treat dev database with same security as production

## Troubleshooting

### Connection Error

```
❌ Failed to connect to database: could not connect to server: Connection refused
ℹ️  Make sure PostgreSQL is running and credentials are correct.
ℹ️  Update DATABASE_URL in .env file
```

**Solution:**
```bash
# Ensure PostgreSQL is running
# Linux/Mac: brew services start postgresql
# Windows: Start PostgreSQL service
# Docker: docker run -d -e POSTGRES_PASSWORD=password -p 5432:5432 postgres:15

# Test connection
psql -h localhost -U user -d thergenome_dev
```

### Table Does Not Exist

```
❌ Error: 'patients' table does not exist in database
ℹ️  Run Alembic migrations first: alembic upgrade head
```

**Solution:**
```bash
# Apply migrations
alembic upgrade head

# Verify table created
psql -U <user> -d thergenome_dev -c "\d patients"
```

### Invalid DATABASE_URL Format

```
❌ Error seeding database: (psycopg2.OperationalError) invalid DSN ...
```

**Solution:**
```bash
# Edit .env file with valid PostgreSQL connection string
# Format: postgresql://[user]:[password]@[host]:[port]/[database]
# Example: postgresql://postgres:password@localhost:5432/thergenome_dev

# Test connection
python -c "from sqlalchemy import create_engine; engine = create_engine('postgresql://...'); engine.connect()"
```

### Duplicate Primary Key Error

```
❌ Error seeding database: ... duplicate key value violates unique constraint ...
```

**Solution:**
```bash
# Patients table already has seed data
# Clear existing data:
psql -U <user> -d thergenome_dev -c "TRUNCATE patients;"

# Then reseed:
python scripts/seed_patients.py
```

### Out of Memory

```
❌ Error seeding database: MemoryError
```

**Solution:**
```bash
# Reduce batch size or number of records
python scripts/seed_patients.py 100  # Start smaller

# Or edit scripts/seed_patients.py and reduce BATCH_SIZE
BATCH_SIZE = 50  # Reduce from 100
```

## Advanced Usage

### Reset and Reseed

```bash
# Clear all data
psql -U <user> -d thergenome_dev -c "TRUNCATE patients RESTART IDENTITY CASCADE;"

# Reseed with fresh data
python scripts/seed_patients.py
```

### Generate and Export CSV

```python
# Add to scripts/seed_patients.py
import csv

def export_csv(num_patients=100):
    patients = [generate_synthetic_patient() for _ in range(num_patients)]
    
    with open('patient_seed_data.csv', 'w', newline='') as f:
        writer = csv.DictWriter(f, fieldnames=patients[0].keys())
        writer.writeheader()
        writer.writerows(patients)
    
    print(f"Exported {num_patients} records to patient_seed_data.csv")

if __name__ == "__main__":
    export_csv()
```

### Generate with Custom Demographics

Edit `scripts/seed_patients.py` to customize:

```python
# Adjust age distribution
age = max(18, int(random.gauss(60, 15)))  # Older population: mean 60

# Add more sex options
SEX_OPTIONS = ["M", "F", "Other", "Prefer not to say", "Non-binary"]

# Add custom ethnicity
ETHNICITY_OPTIONS = ["White", "Black", "Hispanic", "Asian", "Indigenous", ...]

# Generate patients with custom function
def generate_critical_patients():
    """Generate patients aged 65+"""
    patients = []
    for _ in range(100):
        p = generate_synthetic_patient()
        while 2026 - p['date_of_birth'].year < 65:
            p = generate_synthetic_patient()
        patients.append(p)
    return patients
```

## Integration with Testing

### Use Seeded Data in Tests

```python
# tests/test_patients.py
import pytest
from sqlalchemy.orm import Session
from app.models import Patient

@pytest.fixture
def seeded_db(db_session: Session):
    """Fixture with pre-seeded test data"""
    from scripts.seed_patients import generate_synthetic_patient
    
    patients = [generate_synthetic_patient() for _ in range(10)]
    for p in patients:
        db_session.add(Patient(**p))
    db_session.commit()
    return db_session

def test_find_patient_by_id(seeded_db):
    patient = seeded_db.query(Patient).first()
    assert patient.first_name is not None
    assert patient.date_of_birth is not None
```

## Maintenance

### Monthly Refresh

```bash
# Clear old seed data and generate fresh records
psql -U <user> -d thergenome_dev -c "TRUNCATE patients;"
python scripts/seed_patients.py 500
```

### Monitor Seed Data

```sql
-- Check when seed data was created
SELECT 
    DATE(created_at) as seed_date,
    COUNT(*) as record_count
FROM patients
GROUP BY DATE(created_at)
ORDER BY seed_date DESC;

-- Find oldest seed data
SELECT 
    AGE(NOW(), created_at) as age,
    COUNT(*) as records
FROM patients
GROUP BY AGE(NOW(), created_at)
ORDER BY age DESC
LIMIT 1;
```
